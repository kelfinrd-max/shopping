# 🛒 Smart Shopping Cart with Coupons

A dynamic and user-friendly *Smart Shopping Cart System* built using *PHP* and *MySQL*, designed to make online shopping smarter and more rewarding!  
This system allows users to add products to their cart, apply valid coupons for discounts, and proceed with a simplified checkout process — all managed through a secure and efficient backend.

---

## 🚀 Features

- 🧾 *Smart Cart Management:* Add, update, and remove products in real-time.  
- 🎟 *Coupon System:* Apply discount codes to reduce total price dynamically.  
- 💳 *Checkout Process:* Smooth and secure checkout with calculated totals.  
- 📦 *Product Database:* All items and coupons are stored and managed in MySQL.  
- 🧠 *Smart Recommendations (optional):* Suggest related or discounted products.  
- 💻 *Admin Panel:* Manage products, coupons, and users easily.  
- 🎨 *Interactive UI:* Clean, responsive, and easy-to-navigate interface.
